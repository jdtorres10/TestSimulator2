# Recording instructions — U.S. Civics Test (128 questions)

**For:** Voice talent / study app audio  
**Purpose:** One audio file per official civics question for the citizenship study website  
**Language:** English only (matches the USCIS oral interview)

---

## What you are creating

- **128 separate audio files** — one file per question, numbered **1 through 128**.
- Each file contains **two parts in one recording**:
  1. The **question** (read exactly as written on the script).
  2. A **clear pause** (about **1 to 1.5 seconds** of silence).
  3. The **answer** (read exactly as written on the script for that question).

The website will play **only the question** when the student is on the question side of a flash card, and **only the answer** when they flip to the answer side. Students tap a speaker (🔊) button to hear each part. You do **not** need to record question and answer as separate files.

---

## File names (required)

Name each file with the **question number only**, using **three digits** and the **`.m4a`** format:

| Question # | File name |
|------------|-----------|
| 1 | `001.m4a` |
| 2 | `002.m4a` |
| … | … |
| 23 | `023.m4a` |
| 128 | `128.m4a` |

- Use **leading zeros** for numbers 1–99 (`007.m4a`, not `7.m4a`).
- Do **not** put words in the file name (no “question”, no question text).
- Deliver all files in **one folder** (e.g. `civics_audio/`).

---

## How to read each take (style)

1. **Do not say** “Question”, “Answer”, or the question number out loud.
2. Read the **question** in a **calm, clear, natural** voice — like a USCIS officer asking once, not like a robot or a spelling bee.
3. **Stop completely** for **1–1.5 seconds** (silent pause).
4. Read the **answer** from the script — same clear, natural tone.
5. **Stop.** Do not add “thanks”, “next question”, or extra commentary.

**Good pattern (what the student hears in one file):**  
*[question text]* → *[short silence]* → *[answer text]*

**Avoid:**  
*“Question 1. What is… Answer. Republic.”*

---

## Script fidelity (important)

- Use the **official question-and-answer script** provided with this job (128 items).
- Read **verbatim** — same wording as the script. Do not paraphrase, simplify, or add words.
- If a question has **more than one acceptable answer** on the script, read **only the answer line(s) marked for recording** (usually the **first** listed acceptable answer, unless the script says otherwise).
- Pronounce names and titles as on the script. If unsure, ask before recording that batch.

## Technical settings (keeps the website fast)

Record and export so files stay **small** and **consistent**:

| Setting | Recommendation |
|---------|------------------|
| Format | **M4A (AAC)** — iPhone Voice Memos default is fine |
| Channels | **Mono** (one channel) |
| Sample rate | 44.1 kHz or 48 kHz |
| Length | Typically **5–20 seconds** per file (depends on question) |

**Before you start a long session**

- Turn on **Airplane Mode** or silence notifications.
- Use a **quiet room** (soft clothes, no fan blowing on the mic).
- Hold the phone **12–18 inches** from your mouth, or use a stable mic stand.
- Do a **test file (`001.m4a`)** and send it for approval on **volume, pace, and pause length**.

**While recording**

- If you stumble, **re-do that question only** — do not leave long false starts in the file.
- Keep **pause length similar** on every question (helps the app split question vs answer).
- Keep **volume consistent** across all 128 files.

## Efficient workflow (suggested order)

1. **Read this sheet once** and record **001.m4a** as a sample → wait for OK on pace and pause.
2. Record in **blocks of 15–20 questions** (matches the study categories), in **numeric order** (001, 002, 003…).
3. After each block, **quick listen** with headphones: question clear? pause? answer clear? wrong file name?
4. Name and save each take **immediately** with the correct number.
5. At the end, confirm you have **exactly 128 files**, numbered **001** through **128**, with **no gaps** and **no duplicates**.

## What NOT to record

- Do **not** record Spanish (the app shows Spanish as text only).
- Do **not** record vocabulary lists (separate feature; not part of this batch).
- Do **not** record wrong-answer options (multiple-choice distractors) — **question + official answer only**.
- Do **not** combine all 128 into one long file for delivery (we need **128 separate files**).
